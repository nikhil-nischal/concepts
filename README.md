# Notes

Study notes organized by subject (HLD, LLD, ...). Use the sidebar to
navigate.

- Edit any `.md` file and refresh the browser — no build step, changes show
  immediately.
- New topics get added here via the `sde-notes` skill (paste a transcript →
  filed and committed automatically).

## Viewing locally
```
cd "Ai Automations/Notes"
python3 -m http.server 8080
```
Then open `http://localhost:8080` in a browser.
