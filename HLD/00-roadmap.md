# HLD Roadmap (Concept & Coding by Shreyansh Jain)

## Overview
Meta video laying out the creator's HLD teaching order: concepts are taught
just-in-time, then a design question is solved using that concept. Bigger
"design X" questions sit later since they need several concepts first; a few
simpler questions appear earlier. Sequencing can shift based on viewer
requests / interview frequency, but the topic order below is the intended
learning path. Use this to number future HLD topic folders in the order
below (01, 02, 03, ...) as notes get added for each.

## Planned Topic Order
1. Networking base: TCP, WebSocket, HTTP, WebRTC
2. Client-server vs peer-to-peer architecture
3. CAP theorem
4. Microservices design patterns — Saga (important), Strangler pattern
5. Scaling from zero to a million users
6. Consistent hashing
7. Back-of-the-envelope estimation (servers, memory, storage math)
8. Design DynamoDB (key-value store, uses consistent hashing)
9. SQL vs NoSQL — which DB to use
10. Design WhatsApp
11. Rate limiter
12. Autocomplete / typeahead system
13. Infra components: Kafka, message queues, proxies, CDN, storage types
    (block storage, file storage, S3), RAID, Bloom filters, Merkle trees,
    gossip protocols, caching
14. Scaling databases: horizontal/vertical partitioning, sharding,
    replication, leader election, indexing

## Notes
- No "correct answer" or fixed course structure for HLD/LLD — this is the
  creator's own sequencing for interview prep.
- Other sources may teach a different order; treat this as one curriculum to
  cross-reference against, not the only path.
