# LLD Roadmap (Concept & Coding by Shreyansh Jain)

## Overview
Meta video laying out the creator's LLD teaching order. Prerequisites first
(OOP, then SOLID), then design patterns are introduced a few at a time —
not all 23 upfront — followed by practice questions that apply them. All
practice questions are drawn from real interview questions at product-based
companies. Sequencing of upcoming questions can shift by request/priority,
but the pattern (teach pattern(s) → solve question(s) using them) stays
fixed. Use this to number future LLD topic folders in order as notes get
added.

## Prerequisites
1. OOP fundamentals — inheritance, polymorphism, abstraction (any OOP
   language: C++, Java, Python, etc. works)
2. SOLID principles — always taught first, forms the base for everything else

## Design Patterns
- 23 GoF design patterns total, taught a few at a time rather than all at
  once, interleaved with the questions that use them.

## Practice Questions Covered So Far
Notify-me system, Pizza billing system, Parking lot, Snake and ladder,
Elevator system, Car rental system, Logging system, Tic-tac-toe, BookMyShow,
Vending machine, ATM, Chess, File system, Splitwise.

## Notes
- No fixed course structure for LLD ("no chapter 1, chapter 2") and no
  single correct answer per question — this creator's structure exists to
  make it learnable sequentially.
- Other sources may teach a different order; treat this as one curriculum to
  cross-reference against, not the only path.
